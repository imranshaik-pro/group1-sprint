# Batch 1: independently solved questions and source checks

**Partial review, 17 October 2026:** 100 of 378 questions examined; 278 not yet examined. Across all ten batches, 3,676 questions are still unexamined. The 21 prompts from the earlier collection remain outside this plan.

**Decisions:** 61 confirmed, 7 held, 32 correction required. No new questions were added to scored practice in this documentation-only checkpoint. Existing 50 approved imports are unaffected.

Confirmed means the answer has source support. Correction required means the original question is not release-ready. Held means an ambiguity or authentication gap remains. All dates/figures are tied to the referenced event or publication; historical questions are not silently replaced with a different year’s latest answer. A current publisher page is not a guarantee that every assertion is correct: date, scope and wording are checked separately.

Topic proposals with no existing topic ID identify a syllabus taxonomy gap (for example static festivals/culture); they must not be forced into an unrelated topic. Shared-PSC applicability concerns general knowledge relevance, not a promise of identical state syllabuses.
